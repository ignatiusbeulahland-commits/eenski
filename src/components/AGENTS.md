- Visible copy never explains where things are stored (no "on this device", "in memory", "browser storage"); the only exception is a save failure, which says plainly the browser is out of space and what to do next. Copy failures show the text in the toast so it can be copied by hand. Why: users see product language, not implementation details.
- Page titles, buttons, chips and dropdown options use sentence case (side-menu labels keep their imported title case); stored status values like "In Progress" are sentence-cased when shown (support `sentenceCase`), never with CSS `capitalize`, which capitalises every word. Workspace hero eyebrows share one style: lime `neon-dot` + uppercase lime label. Why: one brand voice across workspaces.
- Small sky-blue labels on light surfaces use `text-sky-text` (plain `text-sky` is too faint for small text); every dropdown or picker trigger needs a spoken name (`FilterSelect label`, `CountryPicker label`); card title links that cover the whole card show focus on the card itself. Why: readable, keyboard- and screen-reader-friendly controls everywhere.
- Learner badge/certificate pop-ups wait while the course completion screen is open (`completionScreenResource`). Why: a pop-up must never cover the completion screen's next step.
