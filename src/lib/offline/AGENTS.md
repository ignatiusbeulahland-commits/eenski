# Offline

- Offline support: `vite-plugin-pwa` (generateSW) writes `/sw.js` into `dist/client`; it is registered only from `lib/offline/register.ts`, which refuses dev, iframes, Lovable preview hosts and `?sw=off`. Pages are NetworkFirst (falling back to `public/offline.html`), hashed pictures CacheFirst, other same-origin pictures StaleWhileRevalidate (never `/og/`), and only JS/CSS/fonts/pictures under 12 KB are precached. Once per release, on fast connections without Data Saver, the main pages (`OFFLINE_PAGES`) and their photos are saved in the background: `lib/offline/pictures.ts` reads each saved page plus the slideshow, cover, catalogue and Charm lists and loads each photo through a detached `<img>` with the page's own `srcset`/`sizes`. Why: public pages show their pictures offline, without making low-data visitors download every photo.
- A new slideshow or picture shown only after page load must be added to `picturesShownLater`, or it won't be there offline.
- Pictures that fail to load are hidden (`img[data-offline-missing]`, set in `site/network/NetworkStatus`) and retried on reconnect; `alt` text stays for screen readers but is never painted (`img { color: transparent }`).
